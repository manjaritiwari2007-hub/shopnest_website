SHOPNEST — SHOPPING WEBSITE DEMO
================================

FILES
- index.html   Main website structure
- style.css    Responsive design and styling
- script.js    Product listing, filters, search, sorting and shopping bag
- README.txt   This guide

HOW TO RUN
1. Extract the ZIP file.
2. Open the shopnest_website folder.
3. Double-click index.html (or open it in Chrome/Edge).
4. Internet is needed for Google Fonts and the remote product photos.

FEATURES
- Modern responsive storefront (desktop, tablet and mobile)
- Product cards with category labels and prices
- Category filters, live search and price sorting
- Add-to-bag shopping cart with quantity controls and remove option
- Cart subtotal
- Newsletter demo interaction
- Mobile navigation

IMPORTANT
This is a front-end learning/demo project. It does not include a real database,
user accounts, inventory, payment gateway, order processing or admin panel.
The checkout button intentionally does not collect payment. Product photos
are loaded from Unsplash URLs and require an internet connection.

CUSTOMIZATION
- Edit product names, prices, categories and image URLs in script.js.
- Change colors and layout in style.css.
- Edit headings, sections and footer text in index.html.

For a real store, connect a secure backend, database and a trusted payment
provider. Never store payment-card details in front-end JavaScript.
